# Calculadora Renda Fixa

Aplicativo web para comparar equivalência líquida entre LCA/LCI e CDB pós-fixados em CDI.

**Idealizador:** Marcelo Amendola

## Publicação
Aplicação estática. Abra index.html ou publique pela funcionalidade GitHub Pages.

## Ícone iPhone
O arquivo apple-touch-icon.png é um PNG quadrado de 180×180 px, sem transparência, referenciado no HTML por caminho relativo. No iPhone, abra o site no Safari e use Compartilhar → Adicionar à Tela de Início.

## Premissas
- Aplicação inicial simulada: R$ 1.000,00.
- Selic atual obtida da série SGS 432 do Banco Central; CDI sugerido como Selic menos 0,10 ponto percentual. Ambos editáveis.
- Rentabilidade pós-fixada expressa em percentual do CDI.
- Capitalização composta com taxa anual constante durante o prazo.
- LCA/LCI isentas de IR para pessoa física.
- CDB tributado no resgate pela tabela regressiva: 22,5% até 180 dias; 20% de 181 a 360; 17,5% de 361 a 720; 15% acima de 720 dias.
- Prazo em meses convertido por aproximação de 30 dias por mês para definir a alíquota.
- Simulação estimativa; não constitui recomendação de investimento.
